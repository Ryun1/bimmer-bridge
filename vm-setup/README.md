# vm-setup: scripts run in the VM

`install.ps1`, `update.ps1`, `uninstall.ps1` and `discover.ps1`, run in the Windows VM by
pasting the hash-checked line `dev/serve.py` prints on the Mac. What each does and how to run
it: [docs/install.md](../docs/install.md#the-scripts-in-the-vm). The lines, the server and the
variables the scripts read: [docs/deploy.md](../docs/deploy.md).
